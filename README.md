**A beginner-friendly guide to understanding Machine Learning fundamentals, popular algorithms, and when to use them.**

Learning Machine Learning can feel overwhelming when you're faced with numerous algorithms, concepts, and evaluation metrics. This repository aims to make that journey simpler by focusing on the essential concepts first, following the **80/20 principle**.

The goal is to help learners build a solid foundation, understand the intuition behind different algorithms, and make informed decisions when selecting a model for a given problem.

## Objectives

- Understand what Machine Learning is and how it works.
- Explore the main types of Machine Learning.
- Learn the core ideas behind popular ML algorithms.
- Understand **when, why, and where** to use different algorithms.
- Build an understanding of the basic Machine Learning workflow.
- Use visual explanations and practical examples to make complex concepts easier to grasp.

## Learning Philosophy: The 80/20 Principle

You don't need to master every algorithm at once.

Start by understanding the concepts that matter most:

1. **Understand the problem** — What are you trying to predict or discover?
2. **Understand the data** — What kind of data do you have?
3. **Understand the algorithm** — How does it work, and what assumptions does it make?
4. **Choose an appropriate model** — Consider the task, dataset, interpretability, and computational resources.
5. **Evaluate the results** — Use suitable metrics and validation techniques rather than relying on accuracy alone.

The focus is on understanding the *intuition before implementation* so that learners can build knowledge progressively.
